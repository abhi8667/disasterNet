The Problem

Centralization Fails

In the moments that matter most, the infrastructure we rely on is the first to collapse.

Single Points of Failure

Cellular towers, power grids, and cloud infrastructure all collapse under the same disaster that demands their use most. There is no fallback when the center fails.

Communication Gaps

Intermittent connectivity disrupts coordination and blocks reliable message propagation — directly increasing mortality during disasters when every second matters.

The Golden Hour Mission

Protect the critical first hour by ensuring responders can locate and prioritize victims without requiring any active internet connection. Every node is a lifeline.

Core Architecture

Peer-to-Peer Gossip Protocol

Each node shares what it knows with its neighbors, propagating critical information across the mesh without any central server.

Decentralized Dissemination

No central broker. No single point of silence. Every node is simultaneously a receiver and relay.

Redundancy Tolerance

Engineered to reduce network storms and strictly limit duplicate messages even in chaotic high-traffic scenarios.

Lean Bandwidth

Message propagation is optimized to work within the strict constraints of disaster-zone radio and local WiFi.

Efficient State Sync

Probabilistic
Bloom Filters

Each node compactly encodes what it has already seen, allowing peers to exchange only what is genuinely missing — minimizing bandwidth across intermittently connected nodes.

01

Node A Shares Bloom Filter

A compact probabilistic representation of all messages node A has seen is transmitted to its neighbor.

02

Node B Computes Delta

Node B checks the filter to determine which messages it holds that A doesn't yet have.

03

Transmit Only the Delta

Only genuinely new data crosses the wire. No redundant transmissions, no network storms.

Security Architecture

Cryptographic Authenticity

Every message is signed using Ed25519 signatures — a high-performance elliptic curve algorithm guaranteeing authenticity and integrity even when relayed through multiple untrusted nodes.

Sybil Attack Defense

Active defenses prevent a malicious actor from flooding the mesh with fake identities. Trust is earned cryptographically, not assumed by proximity or volume.

Anti-Spoofing Layer

Malicious spoofing of responder or victim data is blocked at the protocol level. Every identity claim must be cryptographically verifiable before propagation.

⚠

In a disaster, false data costs lives. DisasterNet treats security as a life-safety requirement, not a feature.
